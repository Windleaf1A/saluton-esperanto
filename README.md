# saluton! — 用中文學 Esperanto

一個以繁體中文設計的互動式 Esperanto 學習平台。

## 功能

- 六個互動文法單元與即時小測驗
- 逐詞拆解、詞尾積木與中文講解
- 英文到 Esperanto 的逆翻譯練習
- 接受多種自然語序的答案
- 內建 ĉ、ĝ、ĥ、ĵ、ŝ、ŭ 特殊字元鍵盤
- 適合桌面與手機的響應式版面

## 線上版本

- [GitHub Pages](https://windleaf1a.github.io/saluton-esperanto/)
- [Sites 私人版本](https://saluton-esperanto-tw.eliohsw-pro.chatgpt.site)

## 本機開發

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

文法架構參考 [lernu!](https://lernu.net/gramatiko?hl=en)，介面文字與互動解說為本專案重新撰寫。
